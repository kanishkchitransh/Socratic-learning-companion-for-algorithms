# Raw PDF Data

This directory contains the source materials for the Socratic learning companion.

## Directory Structure

- `mit_6006_lectures/` - Upload MIT 6.006 (Introduction to Algorithms) lecture materials here
- `kleinberg_tardos/` - Upload Kleinberg-Tardos "Algorithm Design" book materials here

## Instructions

1. Place your PDF files in the appropriate subdirectories
2. MIT 6.006 lecture PDFs should go in `mit_6006_lectures/`
3. Kleinberg-Tardos book PDFs should go in `kleinberg_tardos/`

## Note

This directory is gitignored to avoid committing large PDF files to version control.
The PDFs will be processed and stored as embeddings in the vector database.
